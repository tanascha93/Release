# Kräuterklatsch Studio – Releases

Dieses öffentliche Repository enthält ausschließlich veröffentlichte Windows-Installations- und Updatepakete von **Kräuterklatsch Studio**.

Der Quellcode liegt getrennt in einem privaten Repository.

## Installation

Die jeweils aktuelle Windows-Version wird über **GitHub Releases** bereitgestellt. Der Installer und die von Velopack erzeugten Updatepakete werden automatisch durch GitHub Actions veröffentlicht.

> Hinweis: Solange die Anwendung noch nicht code-signiert ist, kann Windows SmartScreen beim ersten Start eine Warnung anzeigen.
